# me.md — what an AI agent needs to know about you

[← Choose language](README.md) · [Русский](README.ru.md)

An interview template: the AI asks you questions one at a time and builds `me.md` — a short manual about you for any agent (Claude, ChatGPT, Cursor), so you never have to re-explain yourself.

## How to use
1. Open [me-interview.en.md](me-interview.en.md) and copy the whole file.
2. Paste it into an AI chat and type "Let's start".
3. Answer the questions, then correct the draft.
4. Save the result as `me.md` and connect it to your projects. From then on the agent keeps it updated.
