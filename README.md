# me.md

**🇷🇺 Русский** · [🇬🇧 English](#english)

Шаблон-интервью: ИИ задаёт тебе вопросы по одному и собирает `me.md` — короткую инструкцию о тебе для любого агента (Claude, ChatGPT, Cursor). Чтобы не объяснять себя заново в каждом чате.

### Как пользоваться
1. Открой [me-interview.md](me-interview.md) и скопируй его целиком.
2. Вставь в чат с ИИ и напиши «Давай начнём».
3. Отвечай на вопросы, потом поправь черновик.
4. Сохрани результат как `me.md` и подключи к своим проектам. Дальше агент дописывает его сам.

<a id="english"></a>
**🇬🇧 English**

An interview template: the AI asks you questions one at a time and builds `me.md` — a short manual about you for any agent (Claude, ChatGPT, Cursor), so you never have to re-explain yourself.

### How to use
1. Open [me-interview.en.md](me-interview.en.md) and copy the whole file.
2. Paste it into an AI chat and type "Let's start".
3. Answer the questions, then correct the draft.
4. Save the result as `me.md` and connect it to your projects. From then on the agent keeps it updated.
