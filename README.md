# me.md — кто я для ИИ

Шаблон-интервью: ИИ задаёт тебе вопросы по одному и собирает файл `me.md`. Этот файл потом можно давать любому ИИ (Claude, ChatGPT, Cursor), чтобы не объяснять себя заново в каждом чате.

## Как пользоваться
1. Открой [me-interview.md](me-interview.md) и скопируй его целиком.
2. Вставь в чат с ИИ и напиши «Давай начнём».
3. Отвечай на вопросы, потом поправь черновик.
4. Сохрани результат как `me.md` и подключай к своим проектам.
