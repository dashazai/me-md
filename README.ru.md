# me.md — что агенту нужно знать о тебе

[← Выбор языка](README.md) · [English](README.en.md)

Шаблон-интервью: ИИ задаёт тебе вопросы по одному и собирает `me.md` — короткую инструкцию о тебе для любого агента (Claude, ChatGPT, Cursor). Чтобы не объяснять себя заново в каждом чате.

## Как пользоваться
1. Открой [me-interview.md](me-interview.md) и скопируй его целиком.
2. Вставь в чат с ИИ и напиши «Давай начнём».
3. Отвечай на вопросы, потом поправь черновик.
4. Сохрани результат как `me.md` и подключи к своим проектам. Дальше агент дописывает его сам.
